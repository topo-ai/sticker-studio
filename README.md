# Sticker Studio · 表情包工作室

从原创角色参考图出发，策划和制作静态、动态表情套系，完成帧序列处理、质量检查，以及微信和抖音投稿物料准备。

当前版本：**2.2.3**。Skill 入口：[SKILL.md](SKILL.md)。

## 能做什么

- 角色识别特征、画风与套系主题设计。
- 情绪、动作分镜、连续帧与有意文字动效规划。
- GIF、动画 WebP、PNG 编码与透明边缘检查。
- 主体漂移、网格切分、眼睑过渡及动作节拍诊断。
- 微信、抖音各自的素材规格、表单文案和授权核查流程。
- 交付文件按 `01-收到.gif` 命名，并附逐张含义词清单。

图像生成由使用环境中可用的图像工具完成；本仓库的 Python 脚本负责项目管理和媒体处理。需要实际播放审阅动作与角色一致性，脚本通过不代表视觉或平台审核通过。

## 在 Codex 中使用

将仓库下载或克隆到 `~/.codex/skills/sticker-studio`，保持 `SKILL.md` 位于该目录根部。重新加载技能后，可使用：

> 使用 $sticker-studio，参考这个角色制作一套16张动态聊天表情，包含中文文件名、含义词和微信投稿素材。

Python 依赖：

```sh
python -m pip install -r requirements.txt
python scripts/studio.py doctor
```

处理视频需安装 FFmpeg/FFprobe，并保证在 PATH 中可调用。具体工作模式和命令见 [SKILL.md](SKILL.md)。

## 发布范围

微信与抖音的表情商店投稿规则分别维护，规则可能变化，投稿前需复核当前账号表单。实际上传、接受协议及提交在用户授权范围内执行；不保证上架。角色原图、生成表情成品、账号信息和个人工作记录不随仓库提供。
