# 故障定位与返工

| 症状 | 判断与处理 | 不允许的掩盖 |
|---|---|---|
| 画面仍有棋盘 | 真Alpha缺失→回生成/明确抠像路线 | 棋盘图直接编码 |
| 前景同幕色丢失 | 选幕色错误→换背景或分割工具 | 全局删除幕色，破坏同色服装 |
| 帧表跨格 | 格间距或构图错误→重出候选 | 裁掉手脚继续交 |
| 动作忽大忽小 | 检查源比例→用共同缩放；源已漂移则重生 | 每格各自拉满 |
| 角色变脸/换衣 | 使用同一母版修受影响帧 | 宣称是“动作夸张” |
| GIF单帧/重复图 | 实际帧数与像素变化检查→补姿势 | 多复制同帧伪装动态 |
| 接点跳变 | 修末/首动作与过渡，再调时长 | 只把播放减慢 |
| 金币/文字逆流 | 单向事件不适合倒放→设计归位 | 无脑boomerang |
| 字错/闪动 | 统一文字方案，定向图像编辑或获授权合成 | 未核实就说“可读” |
| 超过体积 | 从原帧降低纹理/颜色/无效帧，核对平台允许尺寸 | 缩到错误尺寸却标合规 |
| 动画可用但缺一条 | 保留成功项和失败清单，状态partial | 偷减pack数量 |
| 审阅后换文件 | 哈希失效→重验相关项 | 复用旧PASS |
| 投稿超时 | 查记录/草稿/回执后决策 | 连点提交制造重复 |

日志记录：item id、版本、观察到的问题、分类、影响文件、下一动作、重试次数、剩余阻塞。两轮同类失败后改路线或报告，不无限尝试。
