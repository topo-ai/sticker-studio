# 抖音

官方表情入口：https://effect.douyin.com/emoji 。官方制作与审核文档：https://effect.douyin.com/content/3qfpb69n/vu665qm8#863320c7 。2026-10-22已通过官方网页读取公开规范；账号投稿表单、授权协议和回执仍需逐次核对。

## 表情商店投稿

支持单品和系列两类。系列数量按素材规范为8/16/24张；文档概述另写8–24张，实际选项以账号表单为准。动态主图支持GIF/WebP，静态支持JPG/PNG/GIF/WebP；同一系列统一动静，动态永久循环。主图尺寸240×240至1000×1000，系列为1:1，大小原文为“不大于5M”。透明PNG封面1张，240×240至1000×1000、1:1，大小原文为“不大于10MB”。大小单位未换算成平台实际字节阈值；制作时留余量，上传后验证。

标题最多12个汉字，8个以内显示较好；简介最多40个汉字；单表情名称最多4个汉字；版权署名最多12个汉字。检查文案对应画面、系列差异、透明边缘与实际聊天尺寸。上架后官方说明的发现入口包括聊天和视频评论的表情面板。

流程：抖音账号登录 → 查看账号可用单品/系列表单 → 同一草稿内测试一张的上传与播放 → 补齐系列和封面/字段 → 审阅当前授权条款 → 在用户明确授权范围内提交 → 保存审核回执 → 实际搜索与添加验收。官方预计审核时间不作为完成保证。

官方质量规则禁止重复素材和同一批素材多账号上传。因此测试优先使用草稿上传预览，不先发布单品再假定同一文件能作为系列重发。没有账号入口或授权条件不明时记录卡点，不编造上架结果。

公开创作者服务协议线索：https://lf26-cdn-tos.draftstatic.com/obj/ies-hotsoon-draft/effect_platform/protocolAuth.html 。其中出现排他使用等授权措辞；实际上传前核对当前适用版本、授权范围和用户计划的多平台用途，不默认多个平台许可相容。不能代用户勾选尚未获确认的绑定协议。

## 作品展示

图片/视频发布是另一条能力。官方文档：https://open.douyin.com/platform/resource/docs/ability/content-management/douyin-publish-solution/ 。静态可做合集卡片，动态可用MP4展示；看视频不等于可收藏为聊天表情。

企业私信素材接口：https://open.douyin.com/platform/resource/docs/develop/common-tools/material-repo 。其GIF参数只属于该接口，不能套用表情商店。SDK/API需相应申请与授权，不能凭文档存在声称已经接入。

按目标交付通用表情、经核验的投稿素材包、展示封面与文案；不承诺激励收入、特定推荐量或自动获准发布。
