# 02 · 角色资产与风格

查看原参考，分离身份与绘制风格；登记 character.json 的 reference_paths、master_path、invariants、allowed_variations。只有用户提供或图中可见的信息能算身份事实。卡通性格是角色的表演设定，不能当真实人物性格推断。

## 角色设计卡

| 层次 | 需要锁定 |
|---|---|
| 轮廓 | 人/动物/团子结构、头身比、主要突起位置、肢体数量 |
| 面部 | 眼睛、眉、嘴、眼镜、腮红、可接受的简化幅度 |
| 服装与道具 | 关键服装结构、标志配饰、道具是否可拆换 |
| 颜色 | 主体、轮廓、强调色与色幕冲突风险 |
| 线与质感 | 蜡笔、墨线、扁平、材质、阴影复杂度 |
| 表演范围 | 可夸张的部位、不允许变形的识别点 |

头像改全身时，下半身是新设计，明确记录，不把推测视为原设定。关键角度缺失时先补最少必要角度；小幅正面表情不必强行生成三视图。

## 母版生成与锁定

读所选风格 preset，使用 [母版提示词](../prompts/character-master.md)。图像工具输入原参考，若是本地图片先查看；生成后检查：识别点、比例、线条、配色、小尺寸可读性、真实 Alpha。保存原候选和选定母版，不覆盖用户原图。

同一套所有后续图片引用同一母版，不链式引用上一个可能漂移的动作。必要时同时给原参考和母版，分别说明身份与风格职责。工具若不支持多参考要明确选择，不发明 seed/session 参数。

## 角色类型示例

- 人形角色：保留发型、眼镜和服装配色等识别点，统一 Q 版比例。服装与幕色相近时，优先真 Alpha 或选择不同幕色。
- 团状吉祥物：保留轮廓突起、线条质感、五官与腮红位置，不擅自添加人类肢体。道具可按主题替换，但应保持角色轮廓与持物方式一致。

修改母版会影响所有动作和相应导出/视觉审阅。只改一个动作的台词不应使整套角色母版失效。
