# 角色母版提示词

```text
Create a reusable single-character master for a chat sticker series.
Input references: [file and role: original identity / selected style].
Preserve exactly: [visible invariants].
Allowed redesign: [head-body ratio, simplification, requested style changes].
Style: [selected preset, palette, outline and shading].
Pose: one neutral readable pose, whole figure, comfortable margins.
Background: [native transparent alpha if supported; otherwise explicit safe screen].
No labels, grids, extra characters or scenery. Do not reproduce reference background.
```

不是每个角色都要全身：原始团子没有腿时不补腿。每张参考先查看；缺失角度不凭空编细节当身份事实。
