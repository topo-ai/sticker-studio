# 动作库与节奏

这是分镜起点，不是把单图做整体抖动的程序预设。根据真实角色肢体和道具改编；团子只有小手就不要突然长人类长腿。每条只选一个主动作，最多一个辅助光点/汗滴。

| key | 结构 | 接点与风险 |
|---|---|---|
| salute | 手从胸前抬到额侧→停留→放回 | 眼镜别被手覆盖后消失 |
| typing | 左右手交替敲击→短停→继续 | 键盘不变形，手不能多指 |
| glasses-sigh | 推眼镜→垂眉/张小嘴→手落 | 表情变化不变脸 |
| peek | 眼神转侧→小幅探头→回正 | 摄像机固定，笔记本锚定 |
| sleepy | 眼皮降→头垂→回抬 | 不能用整张旋转称点头 |
| run-cycle | 接触→下压→蹬离→腾空→换脚 | 周期姿态闭合，手臂反相 |
| hug-ingot | 举元宝→抱紧→放松→归位 | 手与道具接触关系连续 |
| count-coins | 摘一枚→移到另一侧→放下 | 禁简单倒放“钱飞回手里” |
| beckon | 手伸出→弯曲招手→展开 | 主体不整体拉伸失形 |
| parcel-lift | 托住→上举→停留→放回 | 包裹尺寸数量固定 |
| payday | 看手机→喜悦→小拳头上举→归位 | 无真实账户/金额信息 |
| greeting | 双手抱拳→举高→落回 | 手在一起，形体稳定 |

八姿势时长示例（毫秒）：200,140,140,180,300,140,140,200，总时长1440ms。峰值不一定在第五帧，按实际分镜改，不能照抄索引。重复静止帧由编码器合并是正常的，只要实际时长正确。

低帧率/有限动画：可有明显姿势停顿，但应称“关键帧风格”。不满足自然流畅时不能宣传成高帧率动画。透明细颗粒/蜡笔噪点会增大 GIF，优先保持角色轮廓，再控制纹理变化。
