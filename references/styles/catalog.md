# 风格与覆盖优先级

顺序：用户当前明确要求 > 已确认角色母版 > 项目选择 > 根据参考推荐。风格只决定绘制方式，不能覆盖身份、主题或平台格式。每套锁定一种主风格，不混搭导致换角色。

| id | 用途 | 模块 |
|---|---|---|
| handdrawn-soft | 手绘团状角色、温柔萌趣 | [手绘柔软](presets/handdrawn-soft.md) |
| chibi-ink | 人形头像到Q版、打工吐槽 | [Q版墨线](presets/chibi-ink.md) |
| flat-bold | 字少、轮廓强、低体积 | [扁平醒目](presets/flat-bold.md) |
| clay-toy | 原创角色的3D黏土改编 | [软陶玩偶](presets/clay-toy.md) |

配色保持角色本色，主题道具加一到两个强调色。布局有独立单张、动作帧表、社媒展示卡三种，不因风格 preset 强制九宫格。实际输出背景与描边由工具能力/目标入口决定。
